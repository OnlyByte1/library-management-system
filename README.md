# 📚 Library Management System

Веб-приложение для автоматизации учета и управления библиотечным фондом. Система позволяет вести базу данных книг, отслеживать их доступность и управлять статусами бронирования в реальном времени.

![Интерфейс приложения](https://github.com/user-attachments/assets/c6f44c94-23aa-4cc5-9651-27c8d1860682)

## ✨ Функционал приложения

* **Каталог книг:** Отображение доступной литературы с обложками, авторами и уникальными номерами ISBN.
* **Фильтрация и сортировка:** Быстрый поиск по библиотечному фонду, фильтрация по статусу (Все, Доступна, Выдана) и сортировка по новизне.
* **Система бронирования:** Интерактивные кнопки для бронирования книг пользователями.
* **Ролевая модель:** Поддержка гостевого входа и авторизации пользователей.

## 🛠 Стек технологий

Проект реализован как полнофункциональное Full-Stack приложение:

* **Backend:** Node.js, Express.js
* **База данных:** SQLite (для надежного хранения данных)
* **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3
* **Инструменты сборки и качества:** Vite, ESLint

## 📂 Структура проекта

* `/server` — Логика бэкенд-сервера (API-маршруты, контроллеры, база данных SQLite).
* `/src` — Исходный код фронтенд-приложения на React (компоненты интерфейса, логика запросов).
* `/public` — Статические ресурсы (иконки, изображения обложек).
* `vite.config.js` — Конфигурация сборщика Vite.
* `eslint.config.js` — Настройки линтера для поддержания чистоты кода.

## 🚀 Как запустить проект локально

### 1. Клонирование репозитория
```bash
git clone https://github.com/OnlyByte1/library-management-system.git
cd library-management-system
```

### 2. Запуск серверной части (Backend)
Откройте терминал, перейдите в папку сервера, установите зависимости и запустите API-сервер:
```bash
cd server
npm install
npm run dev
```

### 3. Запуск клиентской части (Frontend)
Откройте **второе окно терминала**, перейдите в корень проекта, установите зависимости фронтенда и запустите Vite:
```bash
# Если вы находитесь в папке server, сначала вернитесь назад:
cd ..
npm install
npm run dev
```
После запуска клиентская часть будет доступна в браузере по адресу: `http://localhost:5173`.
